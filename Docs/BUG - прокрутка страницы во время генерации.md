# Баг: прокрутка страницы во время генерации текста

## Описание

Во время генерации ответа нейронной сетью страница чата должна автоматически прокручиваться вниз по мере появления нового текста.

Сейчас при потоковой генерации текста прокрутка работает некорректно: содержимое продолжает увеличиваться, но положение страницы не удерживается внизу. Из-за этого пользователю приходится вручную прокручивать чат, чтобы видеть продолжение генерируемого ответа.

## Ожидаемое поведение

- Во время потоковой генерации чат автоматически следует за последним появляющимся текстом.
- Пользователь всегда видит актуальный конец генерируемого сообщения.
- После завершения генерации прокрутка остаётся внизу.
- Если пользователь намеренно прокрутил чат вверх во время генерации, автоматическая прокрутка не должна насильно возвращать его вниз до тех пор, пока он снова не приблизится к нижней границе.

## Что проверить

- Обновление высоты блока сообщения во время потоковой генерации.
- Вызов прокрутки после добавления очередной порции текста.
- Корректность работы с контейнером чата, а не со всей страницей браузера.
- Поведение при большом количестве уже существующих сообщений.
- Поведение при ручной прокрутке пользователем во время генерации.
