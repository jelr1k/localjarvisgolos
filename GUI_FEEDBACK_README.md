# Заметки по текущему состоянию GUI

Ветка: `gui`

Этот файл фиксирует результаты последней ручной проверки и задачи на следующие проходы. Это список замечаний, а не описание уже внесённых исправлений.

## Текущее состояние

- **Classic:** в целом выглядит нормально и подходит как база для дальнейшей разработки.
- **Главная анимация:** текущая пульсация наконец-то хорошо заметна и выглядит удачно. Сохранить её как визуальный ориентир для дальнейшей анимации интерфейса.
- **NEXUS:** в остальном выглядит приемлемо, можно развивать дальше после решения замечаний ниже.

## Замечания по NEXUS

1. **Подлагивания при перетаскивании карточек настроек.** Граф всё ещё заметно подтормаживает во время drag-and-drop. Нужно отдельно проверить причины лишних перерендеров и обновлений состояния, не ухудшая плавность взаимодействия.
2. **Масштаб и раскладка отображаются в каждой карточке.** Эти элементы не должны дублироваться внутри каждой карточки графа. Нужно определить для них правильное общее место в интерфейсе NEXUS и убрать повторение из карточек.

## Следующие визуальные улучшения

- Добавить **больше анимаций** в интерфейс: аккуратные переходы между страницами и панелями, появление карточек и окон, реакции кнопок и переключателей, состояния загрузки и раскрытия элементов.
- Сохранять единый стиль движения: анимации должны ощущаться частью одного интерфейса, а не набором случайных эффектов.
- Не жертвовать производительностью ради эффектов. В первую очередь проверить поведение NEXUS при перетаскивании карточек.
- Учитывать режимы движения `full`, `reduced` и `off`: дополнительные эффекты должны уважать выбранную настройку и не ломать доступность интерфейса.

## Приоритет следующей работы

1. Устранить лаги при перетаскивании карточек в NEXUS.
2. Убрать повторяющиеся элементы масштаба и раскладки из карточек NEXUS.
3. После этого расширять набор анимаций и микровзаимодействий по всему интерфейсу.

**Ограничение текущего прохода:** код не исправлялся. Этот документ только фиксирует замечания и направление дальнейшей работы.
