# JARVIS — локальный чат с Ollama

Стартовая архитектура для локального Джарвиса на Python + PySide6 + Ollama.

## Возможности

- чат с локальными моделями через Ollama;
- потоковый вывод ответа;
- выбор модели;
- переключатель режима раздумывания;
- статистика каждого запроса;
- токены входа/выхода/всего;
- скорость генерации в токенах/сек;
- время генерации;
- TTFT — приблизительное время до первого токена;
- температура и размер контекста;
- сохранение настроек в `config/settings.json`;
- отдельный слой LLM, чтобы позже добавить другие движки;
- отдельный слой сервисов и UI;
- заготовка под будущие модули Джарвиса.

## Установка

1. Установи Python 3.11+.
2. Установи Ollama и скачай модели.
3. В терминале:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

4. Запусти Ollama.
5. Запусти:

```bash
python main.py
```

Linux/macOS:

```bash
source .venv/bin/activate
python main.py
```

## Конфигурация

`config/settings.json` создаётся автоматически.

Главные параметры:

- `ollama.base_url`
- `model`
- `thinking`
- `temperature`
- `context_length`
- `max_tokens`

## Важный момент про раздумывания

Приложение передаёт `think` в запрос Ollama. Это поддерживается современными версиями Ollama и моделями, которые умеют управлять thinking/reasoning.

Если конкретная модель не поддерживает этот параметр, поведение зависит от самой модели/Ollama.

## Архитектура

`llm/` — связь с языковой моделью.

`services/` — логика приложения.

`ui/` — графический интерфейс.

`core/` — ядро и конфигурация.

`modules/` — будущие расширения Джарвиса.

`chat/` — история и сообщения.

`data/` — будущие данные, логи и история диалогов.

## Добавление нового движка

Создай класс в `llm/`, унаследованный от `LLMProvider`, и реализуй `stream_chat()`.

Интерфейс и сервисы при этом менять минимально.
