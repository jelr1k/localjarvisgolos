# Баг: закрытие приложения не работает при несовпадении имени ярлыка и процесса

## Статус

Не исправлен.

## Описание

При запуске приложения через ярлык имя объекта в Workspace может не совпадать с именем реально запущенного процесса Windows.

Пример с Telegram:

- ярлык в Workspace: `Telegram`
- реальный основной процесс: `Telegram Desktop`
- дочерний процесс: имя пользователя Telegram, например `шпалтер консерва`

Из-за этого Jarvis не может надёжно найти запущенное приложение только по имени ярлыка/объекта и закрыть его через текущую логику сопоставления процессов.

## Наблюдаемое поведение

Команда вида `закрой Telegram` не закрывает уже запущенный Telegram, хотя приложение было запущено через соответствующий ярлык.

## Предполагаемая причина

Текущая логика закрытия приложения умеет работать с реальным исполняемым файлом и деревом дочерних процессов, но в данном сценарии имя ярлыка (`Telegram`) не совпадает с именем основного процесса (`Telegram Desktop`). Дополнительные дочерние процессы также могут иметь полностью другие имена.

## Что требуется исследовать

Нужно определить надёжную связь между добавленным ярлыком и реально запущенным приложением, не полагаясь только на совпадение отображаемых имён процессов.

Возможные направления для исследования:

1. Разрешать `.lnk` до его целевого исполняемого файла и использовать этот путь как основной идентификатор приложения.
2. При запуске через ярлык сохранять информацию о фактически запущенном процессе/дереве процессов, если это возможно надёжно сделать.
3. При закрытии сначала искать процесс по целевому исполняемому файлу, а имя использовать только как резервное сопоставление.
4. Проверить особенности Telegram Desktop, включая основной процесс и дочерние процессы, чтобы не завершать случайно посторонний процесс с похожими характеристиками.

## Ограничения

Не считать совпадение имени процесса обязательным условием для закрытия приложения.

Не добавлять системные process-guards в рамках этого бага без отдельного требования.

До реализации необходимо изучить текущую цепочку `Workspace -> запуск ярлыка -> идентификация приложения -> поиск процессов -> закрытие` и выбрать способ идентификации, который работает для Telegram и аналогичных приложений с разными именами ярлыка и процесса.
