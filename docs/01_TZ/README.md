# 01 — Технические задания

Здесь находятся документы, определяющие требования и направление развития Jarvis.

## Документы

- [`TZ_JARVIS.md`](../TZ_JARVIS.md) — актуальное ТЗ проекта, версия 2.4.
- [`TZ_JARVIS_UNIFIED.md`](../TZ_JARVIS_UNIFIED.md) — единое ТЗ, объединяющее текущее состояние и целевое развитие проекта.

## Как использовать

`TZ_JARVIS.md` следует считать основным рабочим ТЗ текущего этапа. `TZ_JARVIS_UNIFIED.md` используется как более широкий архитектурный и долгосрочный контекст.
