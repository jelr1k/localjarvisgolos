# Jarvis — требования к установке

**Ветка:** `osnova`  
**Дата:** 2026-09-17

Этот документ описывает, что необходимо для запуска Jarvis из исходников, зачем нужен каждый компонент и что в будущем должен устанавливать сам установщик.

---

## 1. Что нужно установить отдельно

Это программы, которые являются внешними зависимостями Jarvis и не являются обычными Python-библиотеками из `requirements.txt`.

| Компонент | Зачем нужен | Нужен при запуске из исходников | Кто должен устанавливать |
|---|---|---:|---|
| Python 3.11+ | Запуск самого Jarvis и его Python-кода | Да | Пользователь или будущий установщик |
| Ollama | Локальный сервер для запуска LLM | Да | Пользователь или будущий установщик |
| Локальная LLM-модель | Генерация ответов и выполнение сложных задач через Tool Calling | Да, если используется LLM-режим | Пользователь / установщик через Ollama |

### Python

Jarvis написан на Python. При запуске из исходников требуется Python 3.11 или новее.

Python запускает UI, Command Router, инструменты, голосовой ввод, работу с файлами, процессами и интеграцию с Ollama.

В финальной `.exe`-сборке отдельная установка Python пользователю не должна требоваться, если интерпретатор и необходимые runtime-компоненты будут включены в сборку.

### Ollama

Ollama используется как локальный сервер для работы с LLM. Jarvis умеет обращаться к Ollama, управлять сервером и загружать/выгружать модель из UI.

Ollama является отдельной программой и не устанавливается командой `pip install -r requirements.txt`.

### Локальная модель

Ollama и сама модель — разные вещи.

Ollama предоставляет сервер и механизм запуска модели, а модель содержит сами веса нейросети.

Текущий проект рассчитан на локальную LLM. Конкретная модель может меняться, поэтому модель не следует считать частью Python-зависимостей.

Для текущего рабочего окружения используется модель семейства Qwen. Перед финальной сборкой проекта необходимо зафиксировать точное имя и рекомендуемый размер модели для целевого компьютера.

## 2. Python-библиотеки Jarvis

Эти зависимости перечислены в `requirements.txt` и могут устанавливаться автоматически через `install_dependencies.bat`.

| Библиотека | Назначение |
|---|---|
| `PySide6` | Графический интерфейс Jarvis |
| `requests` | HTTP-взаимодействие с локальным Ollama API и другими HTTP-интерфейсами |
| `psutil` | Работа с процессами и системной информацией Windows |
| `pywin32` | Windows API, COM, работа с ярлыками и системными объектами |
| `pymorphy3` | Морфологическая нормализация русского текста и команд |
| `numpy` | Числовая обработка данных, в том числе аудиоданных |
| `sounddevice` | Захват звука с микрофона |
| `faster-whisper` | Локальное распознавание речи в текст (STT) |
| `pytest` | Запуск тестов проекта |

### Важное разделение

`pytest` нужен в первую очередь для разработки и проверки проекта. В конечной пользовательской сборке он не должен считаться обязательной runtime-зависимостью, если тестовый раннер не включён специально.

Остальные перечисленные библиотеки используются самим приложением или его голосовой подсистемой.

---

## 3. Голосовой ввод

Для голосового режима нужны дополнительные Python-компоненты:

```text
sounddevice
    ↓
захват микрофона
    ↓
faster-whisper
    ↓
текст
    ↓
ChatService / Command Router
```

Текущая конфигурация STT использует локальную модель `small`, CPU, `int8`, русский язык, 16 kHz, `beam_size=5` и VAD.

Модель Whisper не является той же моделью, что используется Ollama для генерации текста. Это отдельная ML-модель голосового распознавания.

При первом использовании `faster-whisper` может потребоваться загрузка соответствующих модельных файлов. Конкретное поведение и способ их поставки нужно отдельно проверить перед финальной `.exe`-сборкой.

---

## 4. Что обычному пользователю устанавливать не нужно вручную

При нормальной автоматической установке пользователь не должен заниматься каждой библиотекой отдельно.

Скрипт:

```text
install_dependencies.bat
        ↓
python -m pip install -r requirements.txt
```

устанавливает Python-зависимости из `requirements.txt`.

Следовательно, отдельно искать и ставить `PySide6`, `psutil`, `pywin32`, `pymorphy3`, `numpy`, `sounddevice`, `faster-whisper` и другие перечисленные Python-пакеты не требуется, если Python и `pip` уже доступны.

---

## 5. Что не является отдельной зависимостью Jarvis

Следующие вещи не нужно считать отдельными обязательными программами Jarvis:

- Windows 11 — это целевая операционная система, а не устанавливаемая библиотека;
- микрофон — аппаратное устройство для голосового ввода;
- браузер — не является текущей обязательной зависимостью;
- CMD/PowerShell — системные компоненты Windows, а не сторонние зависимости Jarvis;
- Git — нужен для разработки и получения исходников, но не обязан быть установлен у конечного пользователя готовой сборки;
- VS Code и другие IDE — инструменты разработки, а не зависимости Jarvis.

---

## 6. Как должна выглядеть установка в будущем

Целевой пользовательский сценарий должен быть максимально коротким:

```text
Установщик Jarvis
        ↓
проверка Windows
        ↓
установка/подготовка runtime
        ↓
установка Ollama
        ↓
выбор или установка рекомендуемой LLM
        ↓
подготовка Python/runtime-зависимостей внутри сборки
        ↓
первый запуск Jarvis
```

В идеальной конечной `.exe`-сборке пользователю не нужно знать, что внутри используются Python, PySide6, requests, psutil и остальные пакеты.

Пользователь должен видеть прежде всего:

1. Jarvis;
2. Ollama;
3. рекомендуемую локальную модель;
4. настройки голосового ввода и остальных функций.

---

## 7. Что ещё проверить перед финальным установщиком

Перед выпуском `.exe` необходимо отдельно проверить:

- нужна ли пользователю отдельная установка Python;
- какие runtime-компоненты Python попадут в `.exe`;
- нужен ли отдельный Microsoft Visual C++ Runtime для конкретной сборки;
- как распространяется модель `faster-whisper`;
- как распространяется основная LLM через Ollama;
- можно ли автоматически установить Ollama;
- где хранить модели и сколько места они занимают;
- что делать при отсутствии интернета во время первой установки;
- что происходит при уже установленном Ollama;
- что происходит при уже загруженной модели;
- какие зависимости нужны только для разработки и тестов.

Эти пункты не следует считать решёнными до отдельной проверки финальной сборки.
