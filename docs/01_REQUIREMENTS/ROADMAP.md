# Jarvis — дорожная карта

**Дата:** 2026-09-19  
**Ветка:** `osnova`

Этот документ описывает развитие Jarvis после текущего этапа. Он не является источником информации о том, что уже реализовано.

## Ближайшее развитие

- стабилизация Command Router и fallback в LLM;
- защита и подтверждение закрытия приложений;
- улучшение истории LLM;
- стабилизация логирования и тестов;
- улучшение голосового пайплайна Whisper;
- завершение автоматических и пользовательских алиасов.

## Голос

- wake word, по умолчанию `Jarvis`;
- постоянный/активируемый режим голосового ввода;
- локальный TTS;
- улучшение распознавания имён приложений и файлов;
- передача известных имён и алиасов в контекст Whisper.

## Workspace 2.0

Текущий Workspace постепенно должен превратиться из папки с вручную добавляемыми объектами в управляемый индекс доступных приложений и файлов.

Планируется:

- обнаружение приложений Windows при первом запуске или по команде;
- сохранение фактических путей;
- включение и отключение объектов пользователем;
- ручное добавление объектов;
- настройка алиасов;
- повторное сканирование;
- отдельный индекс приложений для быстрого Router.

Не следует бездумно сканировать весь диск через полный `rglob()`. В первую очередь рассмотреть меню «Пуск», зарегистрированные приложения, стандартные каталоги установки, PATH и ручное добавление.

## Расширение доступа к ПК

В будущем возможен контролируемый выход за пределы Workspace через систему разрешений.

Перед таким расширением должны появиться отдельные правила для:

- доступа к файлам вне Workspace;
- запуска скриптов и команд;
- внешнего контента;
- браузерной автоматизации;
- действий, которые могут менять состояние системы.

## Модель и LLM

- скользящее окно истории;
- автоматический Model Router для выбора модели по сложности задачи;
- долгосрочная память;
- специализированные модули;
- дальнейшая оптимизация потребления CPU, RAM и VRAM.

## Финальная сборка

- переносимая `.exe`-сборка;
- автоматическая подготовка зависимостей;
- установка/проверка Ollama;
- подготовка рекомендуемой модели;
- проверка работы без ручного CMD;
- проверка переноса между дисками.
