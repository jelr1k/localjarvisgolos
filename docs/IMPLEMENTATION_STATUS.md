# Статус реализации ТЗ Jarvis

## Реализовано в `chatgpt/auto-detect-install-path`

- [x] Автоматическое определение корня Jarvis для исходников и будущего `.exe`.
- [x] Workspace формируется относительно текущего расположения приложения.
- [x] Пользовательские настройки вынесены в `%APPDATA%\\Jarvis\\settings.json`.
- [x] Пользовательские алиасы вынесены в `%APPDATA%\\Jarvis\\aliases.json`.
- [x] Защищённый sandbox с нормализацией путей.
- [x] Защита от `..`, абсолютных внешних путей, symlink и junction/reparse point через `Path.resolve()`.
- [x] Единая точка выполнения инструментов.
- [x] Повторная проверка разрешений при каждом вызове.
- [x] Файловые инструменты из первой очереди.
- [x] Безопасный поиск приложений через Start Menu/PATH без shell.
- [x] Проверка запущенных процессов.
- [x] Закрытие приложений вместе с их дочерними процессами по PID-дереву.
- [x] Дочерние процессы завершаются до корневого процесса приложения.
- [x] Отдельные подтверждения для опасных действий.
- [x] Фактическая проверка удаления и других файловых операций.
- [x] Прямой Command Router для однозначных русскоязычных команд.
- [x] Система пользовательских алиасов для приложений, файлов, папок и действий.
- [x] Нормализация, точное сопоставление и защита от конфликтующих алиасов.
- [x] Точное разрешение алиасов подключено к ToolExecutor и LLM Tool Calling.
- [x] Fuzzy-match с подтверждением пользователя перед сохранением нового алиаса.
- [x] GUI управления алиасами без ручного редактирования JSON.
- [x] Добавление файлов в Workspace через UI-кнопку и drag-and-drop из Проводника.
- [x] После добавления файла автоматически выбирается тип «Файл» и подставляется имя файла для дальнейшего создания алиаса.
- [x] Разрешение запуска файлов `Workspace` с приоритетом над установленными приложениями.
- [x] Интерактивный выбор при нескольких совпадениях `Workspace` по номеру.
- [x] После выбора запускается конкретный сохранённый файл без повторного поиска по имени.
- [x] Раздельные состояния Ollama Server и модели.
- [x] Запуск/остановка сервера и загрузка/выгрузка модели через UI.
- [x] При закрытии Jarvis сервер Ollama остаётся работать, модель освобождается.
- [x] Логирование с ротацией.
- [x] Unit-тесты sandbox, файловых операций и AliasManager.
- [x] Регрессионные тесты добавления файлов в Workspace.
- [x] GitHub Actions workflow для автоматического запуска тестов.
