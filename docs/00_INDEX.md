# Документация Jarvis

Документация проекта разделена по назначению, чтобы ТЗ, архитектурные материалы, описание отдельных функций, статус реализации и требования к установке не лежали одной кучей в `docs/`.

## Структура

```text
docs/
├── 00_INDEX.md
├── 01_TZ/
│   ├── README.md
│   ├── TZ_JARVIS.md
│   └── TZ_JARVIS_UNIFIED.md
├── 02_ARCHITECTURE/
│   ├── README.md
│   ├── AI_WORK_GUIDE.md
│   ├── PATH_PORTABILITY_TZ.md
│   └── LOGGING_SYSTEM.md
├── 03_FEATURES/
│   ├── README.md
│   └── AUTO_ALIASES_TZ.md
├── 04_STATUS/
│   ├── README.md
│   └── IMPLEMENTATION_STATUS.md
└── 05_INSTALLATION/
    └── INSTALL_REQUIREMENTS.md
```

## Разделы

### `01_TZ`
Основные технические задания проекта.

- `TZ_JARVIS.md` — актуальное ТЗ проекта.
- `TZ_JARVIS_UNIFIED.md` — единое ТЗ с текущим состоянием и долгосрочным направлением.

### `02_ARCHITECTURE`
Документы, описывающие архитектуру и правила работы над проектом.

- `AI_WORK_GUIDE.md` — руководство для ИИ по работе с репозиторием.
- `PATH_PORTABILITY_TZ.md` — требования к переносимости путей и расположения Jarvis.
- `LOGGING_SYSTEM.md` — система диагностического логирования.

### `03_FEATURES`
Документация отдельных реализуемых подсистем.

- `AUTO_ALIASES_TZ.md` — автоматические алиасы и `WorkspaceIndex`.

### `04_STATUS`
Текущее состояние реализации и список оставшихся задач.

- `IMPLEMENTATION_STATUS.md` — фактический статус ветки `osnova`.

### `05_INSTALLATION`
Документы для установки и подготовки окружения.

- `INSTALL_REQUIREMENTS.md` — какие программы, локальные модели и Python-библиотеки нужны Jarvis, зачем они нужны и что устанавливается автоматически.

В результате корень `docs/` содержит только индекс, а сами документы разложены по тематическим подпапкам.
