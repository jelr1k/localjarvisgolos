# Workspace UI

## Назначение

Вкладка Workspace показывает актуальное содержимое разрешённой рабочей папки Jarvis и предоставляет быстрый переход к настройке пользовательских алиасов конкретного объекта.

## Источник данных

UI не сканирует Workspace отдельной логикой. Источником истины является `WorkspaceIndex`.

Для каждого объекта показываются:
- имя;
- тип;
- относительный путь;
- автоматические алиасы;
- пользовательские алиасы.

## Алиасы

Автоматические алиасы вычисляются без записи в пользовательское хранилище. Пользовательские алиасы редактируются через существующий `AliasManager`.

Кнопка должна называться «Настроить алиасы», а не «Создать алиас», потому что объект уже существует, а пользователь добавляет ему дополнительные имена.

## Ограничения

Workspace UI не является вторым файловым менеджером. Не дублирует операции копирования, перемещения и переименования Windows Explorer.
