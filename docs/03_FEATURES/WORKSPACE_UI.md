# Workspace UI

## Назначение

Вкладка Workspace показывает актуальное содержимое разрешённой рабочей папки Jarvis и является основной точкой добавления объектов в Workspace.

## Добавление объектов

Пользователь может:

- нажать «Добавить файл» и выбрать файл через QFileDialog;
- перетащить файл из Проводника в область Workspace.

Повторное добавление уже находящегося в Workspace файла не создаёт второй объект.

## Источник данных

UI не сканирует Workspace отдельной логикой. Источником истины является WorkspaceIndex.

При обновлении Workspace для существующих объектов автоматически регистрируются отсутствующие безопасные алиасы. Регистрация идемпотентна: повторное обновление не создаёт дубликаты и не перезаписывает пользовательские алиасы.

Для каждого объекта показываются:
- имя;
- тип;
- относительный путь;
- автоматические алиасы;
- пользовательские алиасы.

## Алиасы

Alias Manager отвечает за дополнительные имена уже существующих объектов, а не за обязательное добавление объектов в Workspace.

Кнопка «Настроить алиасы» доступна для приложений и файлов. Внутренние типы folders и actions сохраняются для совместимости с существующей логикой Router и WorkspaceIndex, но не используются как отдельные пользовательские типы добавления через Workspace UI.

## Запуск

Любой существующий объект Workspace, который Windows умеет открыть через os.startfile, может быть передан в единый launch path. Это включает файлы, приложения, ярлыки и папки.

## Ограничения

Workspace UI не является вторым файловым менеджером. Не дублирует операции копирования, перемещения и переименования Windows Explorer.
