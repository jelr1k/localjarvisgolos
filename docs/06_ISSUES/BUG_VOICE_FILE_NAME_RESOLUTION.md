# BUG — разрешение имён файлов после голосового ввода

**Статус:** требует проверки/доработки  
**Компоненты:** Whisper/STT, нормализация, WorkspaceIndex, resolver, файловые tools

## Проблема

Whisper может распознать имя файла не точно. Разные файловые команды не должны по-разному трактовать одно и то же распознанное имя.

Пример:

```text
«открой тест точка txt»
        ↓
STT может получить вариант имени с ошибкой
        ↓
resolver ищет только среди реальных объектов Workspace
        ↓
реальный test.txt может быть найден при контролируемом совпадении
```

## Требования

- источник истины о существовании файла — фактическое содержимое Workspace;
- один resolver должен использоваться всеми соответствующими файловыми командами;
- нормализация имени и расширения должна быть общей;
- небольшие ошибки STT допускают контролируемое fuzzy-сопоставление;
- при нескольких реальных совпадениях нельзя выбирать объект случайно;
- нельзя создавать вымышленные кандидаты только на основании текста Whisper.

## Что проверить

1. Одинаково ли работают открытие, чтение, поиск и другие файловые команды.
2. Где выполняется нормализация текста после STT.
3. Где включается fuzzy-поиск и какой порог используется.
4. Показывается ли конкретный найденный объект до подтверждения опасной операции.
5. Есть ли regression-тесты на несколько совпадений и ошибку распознавания.
