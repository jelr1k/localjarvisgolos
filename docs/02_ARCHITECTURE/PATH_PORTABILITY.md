# ТЗ: устранение жёстких путей и зависимостей от расположения приложения

## Результат анализа ветки `main`

Jarvis не должен зависеть от конкретного места установки или буквы диска.

Все внутренние пути должны строиться через `core/app_paths.py`. Поиск Windows-приложений должен использовать системные источники и `PATH`, а Ollama — системный `PATH` или будущий Dependency Resolver.

`http://localhost:11434` остаётся конфигурируемым адресом по умолчанию. `%~dp0` в `start.bat` сохраняется как переносимый способ запуска.

Перед финальной сборкой `.exe` необходимо проверить перенос проекта между каталогами и дисками.
